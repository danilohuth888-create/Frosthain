# ADR 0007 · Eigene RPG-Erfahrung statt Vanilla-XP

**Status:** angenommen · **Datum:** 2026-11-01

## Entscheidung
FROSTHAIN-Erfahrung (EP) ist ein eigener Wert im Charakterbogen, unabhängig von Vanilla-XP. Talente konkurrieren damit nie mit Verzauberungen. Kurve: EP(Stufe) = 150·(Stufe−1)·Stufe (Startwert fürs Balancing). Erfahrung macht Stufen nur verfügbar; der Spieler entscheidet, welche Klasse die Stufe erhält. EP aus Gegnern wird pro Typ und Zeitraum gedeckelt, damit Mobfarmen nicht dominieren.
