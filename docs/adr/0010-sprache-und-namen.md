# ADR 0010 · Sprache von Code, Daten und Dokumentation

**Status:** angenommen · **Datum:** 2026-11-01

## Entscheidung
- Code, IDs, Dateinamen und Javadoc: Englisch (international üblich, gut für Community-Pakete). Build- und Konfigurationsdateien dürfen deutsch kommentiert sein.
- Dokumentation, Diagnosemeldungen für Inhaltsautoren und alle Spieltexte: Deutsch primär.
- Spieltexte nur über Übersetzungsschlüssel; `de_de` ist Pflicht, `en_us` wird geprüft, weitere Sprachen brauchen nur eine Datei.
- Java-Paket `net.frosthain`, Mod-ID `frosthain`; vor der ersten Veröffentlichung endgültig bestätigen.
