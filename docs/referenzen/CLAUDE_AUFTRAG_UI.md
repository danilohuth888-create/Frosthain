# Auftrag an Claude Code

Nutze dieses Paket als **verbindliche Design- und Rechtevorgabe** für den FROSTHAIN-Neustart.

1. Lies README, alle drei UI-Spezifikationen und die Lizenzpolitik.
2. Verwende `referenzen/UI_Mockups.html` als schematische, selbst erstellte Darstellung, **nicht** als ursprüngliches Referenzbild.
3. Entwirf auf dieser Grundlage konsistente, implementierbare Oberflächen für HUD, Talentbaum und NPC-Dialoge.
4. Erhalte das freie Story-Survival und vermeide verpflichtende Königreichsverwaltung.
5. Baue keine urheberrechtlich ungeklärten D&D- oder Community-Inhalte ein.
6. Dokumentiere Abweichungen, liefere testbare Zwischenschritte und sichere Arbeit im Repository.
7. Behaupte nicht, ursprüngliche Bilder oder vorhandenen Code gesehen zu haben, sofern nicht separat bereitgestellt.

Starte mit einem konkreten UI-Implementierungsplan, danach mit einem funktionsfähigen Prototyp unter Beachtung der vorhandenen Projektarchitektur.
